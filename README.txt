Mappák
  index.html          a teljes oldal (itt írhatod át a szövegeket)
  assets/css/main.css színek, betűk, elrendezés
  assets/js/main.js   a visszajelzés (RSVP) űrlap működése
  images/pair.jpg     a közös fotó a nyitó részen

Feltöltés GitHub Pagesre
  1. Készíts egy új repót a GitHubon (pl. "eskuvo"), Public beállítással.
  2. Töltsd fel a mappa TARTALMÁT (az index.html, az assets és az images mappa legyen a repó gyökerében, ne egy külön almappában).
  3. Repó > Settings > Pages > Build and deployment > Source: "Deploy from a branch".
  4. Branch: main, mappa: / (root), majd Save.
  5. Pár perc múlva az oldal itt lesz elérhető:
     https://FELHASZNALONEV.github.io/eskuvo/

Módosítás
  Szerkeszd a fájlt (GitHubon a ceruza ikonnal is lehet), mentsd el (Commit), és az oldal pár perc alatt frissül.
